# 지렁이 정원

최대 12명이 같은 방에서 플레이하는 실시간 지렁이 게임입니다. Node.js 24가 필요합니다.

## 실행

```powershell
cd C:\min
npm install
npm start
```

브라우저에서 http://localhost:3000 으로 접속하세요. HTML 파일을 직접 열면 멀티플레이 서버에 연결되지 않습니다.

## 친구와 플레이

1. 닉네임과 색을 고르고 방 코드(기본값 `GARDEN`)를 입력합니다.
2. `정원 들어가기`를 누릅니다.
3. `초대 링크 복사`로 링크를 전달합니다. 같은 PC의 다른 브라우저 탭에서도 참가할 수 있습니다.
4. 같은 Wi-Fi/LAN의 다른 기기는 서버 시작 시 출력되는 `http://서버IP:3000/?room=GARDEN` 주소로 접속합니다. Windows 방화벽이 연결을 막는 경우 개인 네트워크에서 Node.js의 접근을 허용해야 합니다.

배포된 Vercel HTTPS 주소는 Wi-Fi나 모바일 데이터 어디서든 접속할 수 있습니다. 로컬 실행은 `PORT` 환경변수로 포트를 변경할 수 있습니다. 최고 기록은 각 기기에 저장되며 계정 간 공유되지 않습니다.

## 휴대폰

- 입장하면 주소창을 제외한 화면을 게임에 사용합니다. 세로·가로 회전과 화면 안전 영역을 지원합니다.
- 왼쪽 조이스틱을 원하는 방향으로 끌고, 오른쪽 가속 버튼을 누르세요. 두 손가락을 동시에 쓸 수 있습니다.
- 화면을 직접 터치해 방향을 정할 수도 있습니다. `정원 나가기`로 일반 화면으로 돌아옵니다.
- `친구 초대하기`는 모바일 공유 메뉴를 열고, 지원하지 않는 브라우저에서는 링크를 복사합니다.
- iPhone Safari의 공유 메뉴 또는 Android Chrome의 메뉴에서 홈 화면에 추가할 수 있습니다. 게임에는 인터넷 연결이 필요합니다.
- 연결이 끊기면 자동으로 다시 연결합니다. 약 15초 이내의 재접속은 같은 지렁이를 복원합니다. 그동안 게임 자체는 계속 움직입니다.

## GitHub / Vercel 배포

Vercel Functions의 WebSocket 지원과 Upstash Redis를 사용합니다. `api/play.js`가 Node HTTP 서버를 내보내며 `/play` 경로로 연결됩니다. 정적 화면은 `npm run build`가 `public/`에 생성합니다. GitHub 연결 후 main 브랜치의 변경은 Vercel에서 배포할 수 있습니다.

Vercel Marketplace에서 **Upstash for Redis**를 프로젝트에 연결하고 `REDIS_URL` 환경변수를 설정하세요. 무료 요금제를 사용하는 경우 자동 유료 업그레이드를 끄고 무료 사용량 한도 안에서 운영하세요. Redis와 Vercel 함수는 도쿄 리전을 사용합니다. 저장소에는 `.env.local`이나 `.vercel` 인증 정보가 포함되지 않습니다.

서로 다른 함수 인스턴스가 같은 방을 사용해도 Redis의 잠금과 토큰 검사로 상태를 일관되게 갱신합니다. 연결은 함수 시간 제한 전에 갱신하고, 브라우저 탭에 저장한 재접속 토큰으로 이어갑니다. 빈 방은 삭제하고, 아무 연결도 없는 방은 2분 후 만료됩니다.

## 조작과 규칙

- 마우스 위치, 화면 터치, 왼쪽 조이스틱, 방향키 또는 WASD로 방향을 바꿉니다.
- Space 또는 모바일 ⚡ 버튼을 누르고 있으면 가속합니다. 에너지를 소모하며, 가속하지 않으면 회복됩니다.
- 씨앗을 먹으면 10점씩 얻고 몸이 길어집니다.
- 벽 또는 다른 지렁이 몸에 머리가 닿으면 종료됩니다. 자기 몸은 지나갈 수 있습니다.
- 입장 후 3초 동안 다른 지렁이와의 충돌을 보호합니다. 벽은 피해야 합니다.
- 죽으면 몸이 씨앗으로 바뀌며, `다시 자라기`로 같은 방에 재입장할 수 있습니다.
- 모두 실시간으로 움직이므로 일시정지 기능은 없습니다. 탭을 바꿔도 게임은 계속 진행됩니다.

## 구현 / 검증

`server.js`: 정적 파일 및 WebSocket 연결. `game-hub.js`: 세션과 입장·재접속. `room-store.js`: 메모리 또는 Redis 기반 방 공유. `world.js`: 이동·먹이·충돌. `game.js`: 입력, 모바일 조작, 화면 보간 및 Canvas 렌더링. 외부 이미지·폰트 없이 실행됩니다.

```powershell
npm test
npm run build
# .env.local에 Redis 연결 정보가 있을 때 서버 인스턴스 간 통합 테스트:
node --env-file-if-exists=.env.local --test tests/redis.test.js
```

서버 동기화, 방 분리, 성장, 충돌, 재입장과 접속 종료를 검증합니다.
